FIM-noisy-GRW
================



This repository contains the code related to the article *Observed
Fisher Information in hidden Markov models - Application to a noisy
Gaussian random walk* (Alexandra Lefebvre and Grégory Nuel, 2026) for
the exact computation of the score and the observed Fisher information
matrix (observed FIM) of the log-likelihood of a Gaussian random walk
observed through Gaussian noise. Main functions are contained in the
directory *R_code* along with detailed inputs and outputs. We provide
below a brief overview of main uses of these functions.

# Notation

We consider a Gaussian random walk (GRW) observed through Gaussian noise
composed of a latent Markov chain $X = (X_1,\ldots,X_n)$ and observed
variables $Z = (Z_1,\ldots,Z_n)$ such that $X_1$ is univariate Gaussian
of mean $\alpha$ and variance $\varepsilon^2$, for $i\in\{2,\ldots,n\}$
$$
X_i = X_{i-1} + \varepsilon U_{i-1},
$$ and for $i\in\{1,\ldots,n\}$ $$
Z_i = X_i + \eta V_{i}
$$ where and $\{U_i\}_{i\in\{1,\ldots,n-1\}}$,
$\{V_i\}_{i\in\{1,\ldots,n\}}$ are independent and identically
distributed standard Gaussian variables. The joint distribution of $X$
and $Z$ writes
$$
P(X,Z=z|\theta) = 
g(X_1,\alpha, \varepsilon), \prod_{i=2}^n g(X_i,X_{i-1},\varepsilon) \prod_{i=1}^n g(z_i,X_i,\eta)
$$ where $g(., \mu, \sigma)$ denotes the Gaussian density of mean $\mu$
and standard deviation $\sigma$.

# First and second order derivatives of the log-likelihood

The main function of this document, *grw_der*, is contained in the file
*compute_derivatives.R*. It takes an observed noisy random walk as input
and returns the log-likelihood of the model, its gradient and its
Hessian matrix at any point $(\eta, \varepsilon)$.

Exact values of the score (respectively of the Hessian matrix) computed
with *grw_der* are reported below and compared to approximate ones using
numerical differentiation of the log-likelihood (respectively of the
exact score) using a step $h = 10^{-6}$. As an example, let us report
values computed at point $(\log 0.8, \log 0.6)$ over a dataset of $25$
random walks of length $n=100$ each, simulated with true parameter
$(\eta^*, \varepsilon^*) = (1.1, 0.2)$.

``` r
rm(list=ls())
source("R_code/simulation.R")
source("R_code/compute_derivatives.R")

# simulations 
alpha = 1 # fixed parameter
sim = simu(n = rep(100, 25), eta = 1.1, epsilon = 0.2, alpha = alpha, seed = 42)

data = sim$z
at = c(eta = 0.8, epsilon = 0.6)
h = 1e-6

# Compare exact and approximate values of the score
Exact = grw_der(param = at, data, Hess=FALSE)$score
Approximate = c((grw_der(param = at + c(h,0), data, Hess=FALSE)$loglik - grw_der(param = at, data, Hess=FALSE)$loglik) / h,
                (grw_der(param = at + c(0,h), data, Hess=FALSE)$loglik - grw_der(param = at, data, Hess=FALSE)$loglik) / h)
res = rbind(Exact, Approximate)
colnames(res) = c("$\\log \\eta$", "$\\log \\epsilon$")
knitr::kable(res, caption = "Exact and approximate score (by row, see header column) reported as parital derivative with respect to the parameter in columns (see header row).")
```

# Compare exact and approximate values of the Hessian matrix

# Exemple of application: parameter estimation with the Newton-Raphson algorithm and standard deviation on parameters.

The score and observed FIM are useful in a variety of statistical
inference. Among them, we propose to compute parameter estimates with
the Newton-Rapshon (NR) algorithm and to compute confidence intervals on
parameters.

The file *NR_algo.R* contains the function *optim_NR* for parameter
estimation with the NR algorithm and *init_NR* for initializing
*optim_NR*.

``` r
rm(list=ls())
source("R_code/simulation.R")
source("R_code/compute_derivatives.R")
source("R_code/NR_algo.R")

#simulation
alpha = 1
sim = simu(n = rep(100, 25), eta = 1.1, epsilon = 0.2, alpha = alpha, seed = 42)
data = sim$z
# Estimation with the Newton-Raphson algorithm
init = init_NR(nrep = 10, data = data, verbose = FALSE)
opt = optim_NR(param = init, data = data, niter = 20, tol = 1e-15, verbose = TRUE) 
```

# Additional output of *grw_der*: posterior state densities

Additionally, if *post_x* is set at *TRUE* as input, the function
*grw_der* returns the vector of mean and variance of posterior states
for a given parameter. A graphical representation of a noisy GRW with
observed vector $z$ and \`\`true’’ latent random walk $X$ is drawn below
along with the vector of mean estimates of the latent states and their
95% confidence interval computed with the vector of estimated variances.

``` r
rm(list=ls())
source("R_code/simulation.R")
source("R_code/compute_derivatives.R")
source("R_code/NR_algo.R")

#simulation of a single sequence of length 300
alpha = 1
sim = simu(n = 300, eta = 1.1, epsilon = 0.2, alpha = alpha, seed = 42)
data = sim$z

# Estimation with NR
init = init_NR(nrep = 10, data = data, verbose = FALSE)
opt = optim_NR(param = init, data = data, niter = 20, tol = 1e-15, verbose = TRUE) 
```
